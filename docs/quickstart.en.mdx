## Option 1. One command (macOS / Linux / WSL)

```bash
curl -fsSL https://raw.githubusercontent.com/sdamarketing/tracker_mcp/main/install.sh | bash
```

Greeted by the signature banner (mint→periwinkle gradient on truecolor terminals),
the installer then checks Node.js (installing via nvm if needed), downloads and
builds the server into `~/.traker-mcp`, and launches the interactive wizard:
Tracker token (hidden input), org ID, live credential check against the API,
arrow-key client selector and automatic config write.

Re-running the same command updates the server.

## Option 2. npm

```bash
npm install -g tracker-mcp
tracker-mcp setup
```

## Credentials

You need two values:

| Variable | Where to get it |
|---|---|
| `TRACKER_TOKEN` | OAuth token with `tracker:read` + `tracker:write` scopes — [oauth.yandex.ru](https://oauth.yandex.ru/client/new) |
| `TRACKER_ORG_ID` | [tracker.yandex.ru/admin/orgs](https://tracker.yandex.ru/admin/orgs) → organization id |

For Yandex Cloud / Identity Hub organizations: `TRACKER_AUTH=iam` plus an IAM token.
