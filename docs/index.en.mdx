**tracker-mcp** teaches your AI assistant to work with Yandex Tracker: search and
create issues, run sprints and boards, manage projects, portfolios and goals,
work with checklists, attachments, worklogs and admin catalogs.

## Features

- **187 tools** — complete coverage of the public Tracker v3 API
- MCP tool annotations: reads carry `readOnlyHint`, deletes carry `destructiveHint`
- Every destructive/bulk operation requires `confirm: true`
- `TRACKER_READ_ONLY=1` serves read tools only (80 tools)
- An agent skill with live-tested recipes and API pitfalls:
  `npx skills add sdamarketing/tracker_mcp`
