## Токен никуда не уходит

Сервер общается только с `api.tracker.yandex.net`. Токен хранится в вашем
конфиге клиента или локальном `.env` (в `.gitignore`).

## Аннотации инструментов

Каждый инструмент несёт MCP-аннотации:

- `readOnlyHint: true` — 80 инструментов чтения
- `destructiveHint: true` — все `delete_*`
- Клиенты используют их, чтобы показывать опасные действия отдельно

## Confirm-гард

Все `delete_*` и `bulk_*` (всего 29) отказываются работать без `confirm: true`.
Агент обязан сначала показать вам, что будет удалено или массово изменено.

## Read-only режим

```bash
TRACKER_READ_ONLY=1
```

Сервер зарегистрирует только 80 инструментов чтения — запись физически невозможна.
Идеально для подключения сторонних агентов и демо.
