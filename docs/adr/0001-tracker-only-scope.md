# ADR-0001: Скоуп — только Yandex Tracker

- Статус: принято
- Дата: 2026-10-05
- Задача: YTMCP-6

## Контекст

Альтернатива на рынке (bim-ba/ycli) покрывает Tracker + Wiki + Forms + DataLens
одним инструментом. Встал вопрос: расширяться ли нам за Трекер.

## Решение

**tracker-mcp покрывает только Yandex Tracker API.** Скилл, документация и
инструменты остаются трекер-центричными.

## Причины

- Глубина важнее ширины: наша ценность — выверенный скилл с живыми граблями API,
  честные аннотации и confirm-гард, а не количество сервисов.
- Wiki/Forms имеют другие домены и аудиторию; их добавление размыло бы фокус
  и удвоило поверхность поддержки (185→370+ инструментов).
- Пользователь подтвердил: «нас интересует только Трекер».

## Последствия

- Запросы на Wiki/Forms → отвечаем отказом с указанием на ycli как альтернативу.
- Coverage-метрики меряем только против Tracker API (снапшот 199 страниц).
