# ADR-0003: Документация на docs7, один сайт, RU+EN

- Статус: принято
- Дата: 2026-10-05
- Задача: YTMCP-4

## Контекст

Репозиторий подключён к Context7 docs7 (сайт собирается из папки `docs/` по push).
Аудитория двуязычная; поддержка двух сайтов — лишняя работа.

## Решение

Один docs7-сайт из `docs/`:

- `docs/docs.json` — манифест (схема docs7, mint-тема), groups: «Руководство» (RU)
  и «Guide» (EN) — одинаковые страницы, суффиксы `.ru.mdx` / `.en.mdx`.
- Источник правды — RU-страницы; EN переводится синхронно при правках.
- README ссылается на сайт; узкие технические заметки остаются в `docs/*.md`
  (SETUP.md и пр.) и со временем мигрируют в MDX.

## Последствия

- Каждая правка страницы трогает оба файла — отражено в чек-листе релиза.
- AGENTS.md НЕ входит в docs/ и не индексируется (внутренний, в .gitignore).
