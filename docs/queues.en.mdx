## Queue core

| Tool | API |
|---|---|
| `get_queues` / `get_queue` | [List](https://yandex.ru/support/tracker/ru/api/queues/get-queues) / [Get](https://yandex.ru/support/tracker/ru/api/queues/get-queue) |
| `create_queue` | [Create](https://yandex.ru/support/tracker/ru/api/queues/create-queue) — key is **latin letters only, no digits**; `issueTypesConfig` is immutable |
| `delete_queue` / `restore_queue` | [Delete](https://yandex.ru/support/tracker/ru/api/queues/delete-queue) / [restore](https://yandex.ru/support/tracker/ru/api/queues/restore-queue) (admin, `confirm`) |
| `get_queue_fields` | [Required fields](https://yandex.ru/support/tracker/ru/api/queues/get-fields) |
| `get_queue_tags` / `delete_queue_tag` | [Tags](https://yandex.ru/support/tracker/ru/api/queues/get-tags) |
| Macros: `get_macros_list`, `get_macro`, `create_macro`, `update_macro`, `delete_macro` | [Macroses](https://yandex.ru/support/tracker/ru/api/get-macroses) |

## Local fields

`create_queue_local_field`, `get_queue_local_fields`, `get_queue_local_field`,
`edit_queue_local_field` — [Local fields](https://yandex.ru/support/tracker/ru/api/queues/get-local-fields).
Inside issues they are addressed by compound id `…--fieldKey`.
