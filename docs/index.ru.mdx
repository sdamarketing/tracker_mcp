создавать задачи, вести спринты и доски, управлять проектами, портфелями и целями,
работать с чеклистами, вложениями, трудозатратами и администрированием.

## Возможности

- **187 инструментов** — полное покрытие публичного API Трекера v3
- Инструменты помечены MCP-аннотациями: чтения — `readOnlyHint`, удаления — `destructiveHint`
- Все деструктивные и массовые операции требуют `confirm: true`
- Режим `TRACKER_READ_ONLY=1` отдаёт только чтение (80 инструментов)
- Скилл для агентов с живыми рецептами и граблями API:
  `npx skills add sdamarketing/tracker_mcp`
